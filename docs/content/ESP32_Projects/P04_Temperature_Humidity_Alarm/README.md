# P04 温湿度报警器（Temperature Humidity Alarm）

## 1. 项目简介

本项目用一个 **DHT22 温湿度传感器** 实时监测环境温度和湿度，当温度或湿度超过设定阈值时，通过 **GPIO2 连接的蜂鸣器或 LED** 发出声光报警。项目同时把实时数据通过串口打印出来，方便调试和观察。

通过这个项目，你可以学会：
- 如何给 ESP32 接入单总线数字传感器；
- 如何使用第三方库（DHT 库）读取环境数据；
- 如何根据条件触发报警；
- 如何用 `millis()` 实现非阻塞定时读取。

## 2. 涉及知识点

- 数字传感器（DHT22）单总线通信
- 使用 Adafruit DHT 库读取温度和湿度
- `pinMode()` / `digitalWrite()` 控制蜂鸣器 / LED
- `millis()` 非阻塞定时
- `isnan()` 判断浮点数是否有效
- 串口打印调试信息

## 3. 硬件清单

| 元器件 | 数量 | 备注 |
|--------|------|------|
| ESP32 开发板 | 1 | 如 ESP32-DevKitC |
| DHT22 温湿度传感器 | 1 | 也叫 AM2302，注意不是 DHT11 |
| 有源蜂鸣器 或 LED | 1 | 二选一，有源蜂鸣器直接响 |
| 330Ω 电阻 | 1 | 如果接 LED，必须串联限流 |
| 杜邦线 | 若干 | 母对母 / 公对母根据模块接口选择 |

## 4. 电路连接

### DHT22 接线

DHT22 模块通常有 3 个引脚（VCC、DATA、GND）或 4 个引脚。下面是 3 脚模块的接法：

| ESP32 | DHT22 | 说明 |
|-------|-------|------|
| 3.3V | VCC | 给传感器供电 |
| GND | GND | 共地 |
| GPIO4 | DATA | 数据引脚。某些模块已内置上拉电阻；如果没有，建议在 DATA 和 3.3V 之间接一个 10kΩ 上拉电阻 |

### 报警输出接线（二选一）

#### 方案 A：接有源蜂鸣器

| ESP32 | 有源蜂鸣器 | 说明 |
|-------|------------|------|
| GPIO2 | 正极（+） | 输出高电平时蜂鸣器发声 |
| GND | 负极（-） | 共地 |

#### 方案 B：接 LED

| ESP32 | LED | 说明 |
|-------|-----|------|
| GPIO2 | 正极（长脚） | ESP32 输出高电平点亮 |
| GND | 负极（短脚） → 330Ω 电阻 | 限流电阻必不可少，防止 LED 烧坏 |

**为什么 LED 必须加限流电阻？**
LED 导通后内阻很小，直接接 3.3V 会有很大电流，轻则 LED 很快老化，重则烧毁 GPIO。330Ω 电阻能把电流限制在约 10mA，既安全又足够亮。

## 5. 代码思路

1. **引入库并定义引脚和阈值**：使用 `DHT.h` 库，定义数据引脚、报警引脚、温度/湿度阈值、读取间隔。
2. **初始化**：在 `setup()` 中启动串口、设置报警引脚为输出并关闭、初始化 DHT 对象。
3. **定时读取**：在 `loop()` 中用 `millis()` 每隔 2 秒读取一次温湿度。
4. **数据校验**：用 `isnan()` 判断读取是否成功；失败时立即关闭报警并打印错误。
5. **阈值判断**：如果温度高于 `TEMP_THRESHOLD` 或湿度高于 `HUMI_THRESHOLD`，就把 `ALARM_PIN` 置高；否则置低。
6. **串口输出**：每次成功读取后都把温湿度打印出来，方便观察。

## 6. 关键代码解析

### DHT 对象初始化

```cpp
DHT dht(DHT_PIN, DHT_TYPE);
```

`DHT` 是库提供的类。第一个参数是数据引脚，第二个参数是传感器型号（DHT22）。在 `setup()` 中调用 `dht.begin()` 后，库会自动完成单总线的初始化。

### 非阻塞定时

```cpp
if (millis() - lastReadTime >= READ_INTERVAL) {
  lastReadTime = millis();
  // 读取传感器...
}
```

`millis()` 返回的是开机后的毫秒数。这种方式比 `delay(2000)` 更好，因为：
- 程序在等待期间不会被“卡死”，可以继续执行其他任务；
- 便于以后扩展，比如同时处理按钮、网络等。

### 数据有效性判断

```cpp
if (isnan(temperature) || isnan(humidity)) {
  Serial.println("DHT22 读取失败，请检查电源、接线和读取间隔");
  digitalWrite(ALARM_PIN, LOW);
  return;
}
```

DHT22 读取失败时会返回 NaN（Not a Number）。如果不判断，后面用异常值和阈值比较可能产生不可预期结果。`isnan()` 就是专门用来检查 NaN 的函数。

### 报警逻辑

```cpp
if (temperature > TEMP_THRESHOLD || humidity > HUMI_THRESHOLD) {
  digitalWrite(ALARM_PIN, HIGH);
} else {
  digitalWrite(ALARM_PIN, LOW);
}
```

这里用的是“或”关系，只要温度或湿度任一超标就报警。如果你想“两者同时超标才报警”，可以把 `||` 改成 `&&`。

## 7. 运行效果

上传代码后，打开 Arduino IDE 串口监视器（波特率 115200），你应该看到类似输出：

```text
==============================
P04：温湿度报警器
==============================
DHT22 初始化完成
读取间隔：2000 毫秒
温度阈值：30.00 °C
湿度阈值：70.00 %
温度：26.50 °C  |  湿度：55.20 %
温度：26.60 °C  |  湿度：55.40 %
```

当温度超过 30 °C 或湿度超过 70% 时，串口会打印 `⚠ 警告：温湿度超过阈值！`，同时 GPIO2 上的蜂鸣器会响 / LED 会亮。当环境恢复正常后，报警自动停止。

## 8. 常见问题

### 串口只打印“DHT22 读取失败”

1. **检查接线**：确认 VCC 接 3.3V、GND 接 GND、DATA 接 GPIO4。
2. **检查供电**：DHT22 需要 3.3V ~ 5V 供电。如果模块上有指示灯，看是否点亮。
3. **检查读取间隔**：DHT22 两次读取至少要间隔 2 秒，间隔太短会失败。本代码已设为 2 秒。
4. **上拉电阻**：如果你的模块没有内置上拉电阻，DATA 脚必须外接 10kΩ 上拉电阻到 3.3V。
5. **引脚定义是否一致**：代码里 `#define DHT_PIN 4`，确认实际接的也是 GPIO4。

### 蜂鸣器一直响 / LED 一直亮

- 检查阈值是否设置得太低，室温就已经超过。
- 检查代码里的报警逻辑：正常时是否调用了 `digitalWrite(ALARM_PIN, LOW)`。

### 蜂鸣器接上后 ESP32 复位

- 某些有源蜂鸣器启动电流较大，可能拉低 ESP32 电源电压导致复位。
- 解决方法：把蜂鸣器单独用三极管或 MOS 管驱动，不要直接由 GPIO 供电。

### 串口看到乱码

- 确认 Arduino IDE 串口监视器波特率选的是 **115200**。
- 确认 USB 线能传数据，有些线只能充电。

## 9. 扩展挑战

1. **加入 LCD / OLED 显示**：把温度、湿度、阈值实时显示在屏幕上，不用一直开着电脑看串口。
2. **增加串口命令设置阈值**：发送 `temp=28` 或 `humi=65` 后，程序动态修改阈值。
3. **多传感器报警**：把蜂鸣器改成不同频率的“滴滴”声，温度高时急促、湿度高时缓慢，便于区分报警原因。
4. **记录历史数据**：用数组保存最近 10 次读数，计算平均值，避免偶发噪声导致误报警。
