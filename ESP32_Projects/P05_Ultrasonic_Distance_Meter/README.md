# P05 超声波测距仪（Ultrasonic Distance Meter）

## 1. 项目简介

本项目用 **HC-SR04 超声波测距模块** 测量前方障碍物的距离，并把结果实时显示在 **SSD1306 OLED 屏幕** 上。当物体靠近时，**有源蜂鸣器** 会发出越来越急促的“嘀嘀”声，模拟倒车雷达的效果。

通过这个项目，你可以学会：
- HC-SR04 的触发 / 回响时序；
- 用 `pulseIn()` 测量微秒级脉冲；
- 用 I2C 驱动 OLED 显示文字和数字；
- 根据距离动态控制蜂鸣器频率；
- 用 `millis()` 避免阻塞主循环。

## 2. 涉及知识点

- 超声波测距原理（HC-SR04）
- `pulseIn()` 与微秒级计时
- I2C 总线、SDA/SCL、设备地址
- SSD1306 OLED 显示（Adafruit 库）
- `map()` 把距离映射到蜂鸣器间隔
- `millis()` 非阻塞多任务处理

## 3. 硬件清单

| 元器件 | 数量 | 备注 |
|--------|------|------|
| ESP32 开发板 | 1 | 如 ESP32-DevKitC |

## 4. 电路连接

### HC-SR04 接线

| ESP32 | HC-SR04 | 说明 |
|-------|---------|------|
| 5V | VCC | 优先使用 5V，测距更稳定 |
| GND | GND | 共地 |
| GPIO5 | Trig | 触发信号，输出 |
| GPIO18 | Echo | 回响信号，输入 |

### OLED（I2C）接线

| ESP32 | OLED | 说明 |
|-------|------|------|
| 3.3V | VCC | OLED 一般 3.3V 供电 |
| GND | GND | 共地 |
| GPIO21 | SDA | I2C 数据线 |
| GPIO22 | SCL | I2C 时钟线 |

### 有源蜂鸣器接线

| ESP32 | 有源蜂鸣器 | 说明 |
|-------|------------|------|
| GPIO19 | 正极（+） | 输出高电平发声 |
| GND | 负极（-） | 共地 |

## 5. 代码思路

1. **引入库并定义引脚**：引入 `Wire.h`、`Adafruit_GFX.h`、`Adafruit_SSD1306.h`，定义 HC-SR04、蜂鸣器、OLED 引脚和地址。
2. **初始化硬件**：在 `setup()` 中设置 GPIO 模式、启动 I2C、初始化 OLED。
3. **测量距离**：用 `measureDistance()` 函数发送 10μs 触发脉冲，再用 `pulseIn()` 读取 Echo 高电平宽度，按声速公式换算成厘米。
4. **显示结果**：用 `updateDisplay()` 把距离和状态提示刷新到 OLED。
5. **蜂鸣器报警**：用 `updateBuzzer()` 把距离映射到蜂鸣器间隔，距离越近间隔越短。
6. **主循环**：每 200ms 测一次距离；蜂鸣器逻辑每次 `loop()` 都检查，保证响应及时。

## 6. 关键代码解析

### 距离换算

```cpp
unsigned long duration = pulseIn(ECHO_PIN, HIGH, 30000);
float distance = duration * 0.034 / 2.0;
```

- `pulseIn()` 返回 Echo 高电平持续的时间，单位 μs。
- 声速约为 `0.034 cm/μs`（340 m/s）。
- 超声波走了“去程 + 回程”，所以总时间对应两倍距离，需要除以 2。

### 无效距离处理

```cpp
if (distance < 2.0 || distance > 400.0) {
  return -1.0;
}
```

HC-SR04 的可靠量程约为 2cm ~ 400cm。超出这个范围的结果不稳定，统一标记为 -1，便于 OLED 显示“超出范围”。

### 蜂鸣器间隔映射

```cpp
int beepInterval = map((int)distance, 0, 100, 100, 2000);
```

`map()` 把距离 0~100cm 线性映射到 100~2000 毫秒。距离越小，间隔越短，蜂鸣器听起来越急促。

### OLED 初始化

```cpp
Wire.begin(SDA_PIN, SCL_PIN);
if (!display.begin(SSD1306_SWITCHCAPVCC, SCREEN_ADDRESS)) {
  Serial.println(F("OLED 初始化失败..."));
  while (true) { delay(100); }
}
```

- `Wire.begin()` 必须显式指定 ESP32 的 SDA/SCL 引脚，否则可能使用错误引脚。
- `SSD1306_SWITCHCAPVCC` 表示使用内部电荷泵从 3.3V 升压驱动 OLED。
- `SCREEN_ADDRESS` 通常是 `0x3C`，如果屏幕不亮可尝试 `0x3D`。

## 7. 运行效果

上传代码后，OLED 会先显示“超声波测距仪 启动中...”，然后开始刷新距离。串口监视器（波特率 115200）会输出类似：

```text
==============================
P05：超声波测距仪
==============================
系统初始化完成
距离：45.3 cm
距离：45.1 cm
距离：12.7 cm
距离：超出范围 / 无回波
```

同时：
- 当障碍物在 **100cm 以内** 时，蜂鸣器开始间断响；
- 当障碍物进入 **30cm 以内** 时，响声变得明显急促；
- 当障碍物进入 **10cm 以内** 时，响声非常急促；
- 当没有障碍物或距离太远时，蜂鸣器不响，OLED 显示“超出范围”。

## 8. 常见问题

### OLED 屏幕不亮

1. **检查 I2C 地址**：把 `SCREEN_ADDRESS` 从 `0x3C` 改成 `0x3D` 试试。
2. **检查 SDA/SCL 接线**：确认 SDA 接 GPIO21、SCL 接 GPIO22。某些板子的默认 I2C 引脚不同。
3. **检查供电**：OLED 一般接 3.3V，不能接 5V（除非模块标明支持）。
4. **扫描 I2C 地址**：在 setup() 中加入 I2C 扫描代码，确认 OLED 是否被识别。

### 距离一直显示“超出范围”

1. 确认 HC-SR04 的 Trig 和 Echo 没有接反。
2. 确认模块正面朝向被测物体，且前方没有柔软/倾斜的吸波材料（如毛毯、海绵）。
3. 如果 VCC 接的是 3.3V，尝试改接 5V。
4. 检查 `pulseIn()` 超时时间是否太短。

### 距离跳变很大

- HC-SR04 对角度和表面材质敏感，轻微晃动或边缘反射会导致跳变。
- 可以连续测量多次取平均值，或在软件中增加中值滤波。

### 蜂鸣器接上后 ESP32 复位

- 有源蜂鸣器启动电流较大，GPIO 直接驱动可能拉低电源。建议用三极管/MOS 驱动，或串联一个 100Ω 电阻试试。

## 9. 扩展挑战

1. **平均滤波**：保存最近 5 次测量值，显示平均值，减少偶然跳变。
2. **OLED 进度条**：根据距离画一条横向进度条，越近进度条越长，像真正的倒车雷达。
3. **多段报警音**：把有源蜂鸣器换成无源蜂鸣器，用 `ledc` 输出不同频率，
   距离不同音调不同。
4. **串口绘图**：把距离通过串口发送到 Arduino IDE 的“串口绘图器”，
   实时观察距离变化曲线。
