# P01 智能小夜灯

## 1. 项目简介

本项目制作一个**根据环境光线自动调节亮度的小夜灯**。当房间变暗时，LED 自动变亮；当房间变亮时，LED 自动变暗甚至熄灭。它把前面教程中学到的 **ADC 模拟输入**和 **PWM 模拟输出**结合起来，是一个典型的"传感器 → 处理 → 执行器"闭环系统。

通过本项目，你可以理解：
- 如何把光敏电阻这种"会随环境变化的电阻"变成 ESP32 能读取的电压信号
- 如何用软件滤波让传感器读数更稳定
- 如何把传感器数据反向映射到执行器输出

### 4.3 为什么光敏电阻要配 10kΩ 电阻？

光敏电阻本身只有两根引脚，它只能改变阻值，不能直接输出电压。把它和 10kΩ 固定电阻串联后，中间点的电压会随光敏电阻阻值变化而变化：

- 光线强 → 光敏电阻阻值小 → 中间点电压低 → ADC 读数小
- 光线弱 → 光敏电阻阻值大 → 中间点电压高 → ADC 读数大

10kΩ 是一个经验值，在室内常见光线范围内能让 ADC 读数有比较明显的变化。如果实际读数范围太小，可以尝试换成 4.7kΩ 或 22kΩ。

## 5. 代码思路

程序的整体流程如下：

1. **初始化**：设置串口、LED 引脚、PWM、ADC 分辨率。
2. **循环读取光线**：每次循环调用 `getAmbientLight()`，连续采样 10 次取平均。
3. **反向映射**：把 ADC 读数通过 `map()` 反向映射到 PWM 占空比。环境越暗（ADC 越大），LED 越亮（PWM 越大）。
4. **输出 PWM**：用 `ledcWrite()` 把目标亮度输出到 LED。
5. **串口打印**：输出当前 ADC 值和 PWM 值，方便观察调试。
6. **延时 100ms**：控制刷新频率，避免 LED 闪烁和串口刷屏。

## 6. 关键代码解析

### 6.1 平均值滤波

```cpp
int getAmbientLight() {
  long sum = 0;
  for (int i = 0; i < SAMPLE_COUNT; i++) {
    sum += analogRead(LDR_PIN);
    delay(1);
  }
  return sum / SAMPLE_COUNT;
}
```

ADC 读数会有噪声，单次读取可能忽高忽低。连续采样 10 次再取平均，可以让光线值更平滑，LED 亮度变化也更稳定。

### 6.2 反向映射

```cpp
targetBrightness = map(lightValue, 0, 4095, 0, 255);
```

`map()` 把 ADC 范围（0~4095）线性映射到 PWM 范围（0~255）。注意参数顺序是：
- 输入最小值 0（很亮）→ 输出最小值 0（LED 暗）
- 输入最大值 4095（很暗）→ 输出最大值 255（LED 亮）

这样就实现了"环境越暗，LED 越亮"的夜灯效果。

### 6.3 范围限制

```cpp
targetBrightness = constrain(targetBrightness, 0, 255);
```

`constrain()` 把数值限制在指定范围内。虽然 `map()` 在输入正常时不会越界，但加上限制可以让程序更健壮，防止意外写入非法占空比。

## 7. 运行效果

上传程序后，打开串口监视器（波特率 115200），应该看到类似输出：

```
================================
ESP32 综合项目 P01：智能小夜灯
================================
用手遮挡或照射光敏电阻，观察 LED 亮度变化
环境光 ADC：512  |  LED 亮度 PWM：31
环境光 ADC：520  |  LED 亮度 PWM：32
环境光 ADC：508  |  LED 亮度 PWM：31
```

实际现象：
- 用手机闪光灯照射光敏电阻：ADC 值变小，LED 变暗甚至熄灭。
- 用手遮挡光敏电阻：ADC 值变大，LED 变亮。
- 正常室内光线：LED 保持中等亮度。

如果 ADC 读数变化方向相反，请检查光敏电阻和 10kΩ 电阻的接线是否接反。

## 8. 常见问题

| 问题 | 可能原因 | 排查方法 |
|------|----------|----------|
| LED 不亮 | LED 正负极接反 | 长脚为正极，接 GPIO2 |
| LED 一直最亮，不随光线变化 | 光敏电阻分压电路接错 | 检查 3.3V→光敏电阻→GPIO34→10kΩ→GND 的串联关系 |
| 光线变暗时 LED 反而熄灭 | map() 方向反了 | 确认是 `map(lightValue, 0, 4095, 0, 255)` |
| LED 亮度剧烈抖动 | ADC 噪声大 | 增大 `SAMPLE_COUNT`，或加 0.1uF 滤波电容 |
| ADC 读数范围很小 | 固定电阻不匹配 | 尝试 4.7kΩ 或 22kΩ |
| 串口输出乱码 | 波特率不一致 | 把串口监视器波特率设为 115200 |

## 9. 扩展挑战

1. **加入亮度阈值**：白天光线足够强时让 LED 完全熄灭，只有低于阈值时才开启夜灯。
2. **校准功能**：用按键或串口命令记录当前环境的"最亮"和"最暗"值，存储到 Preferences 中。
3. **状态显示**：加一块 OLED 屏幕，实时显示环境光 ADC 值和 LED 亮度百分比。
4. **多彩夜灯**：把普通 LED 换成 WS2812B，根据光线强度改变颜色（暗时暖黄光，较亮时白光）。
