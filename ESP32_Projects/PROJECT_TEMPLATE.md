# ESP32 综合项目模板

每个项目目录应包含以下文件：

```
PXX_Project_Name/
├── PXX_Project_Name.ino    # 完整可运行的 Arduino 代码
└── README.md               # 项目详细说明
```

## README.md 结构

1. **项目简介**：这个项目是做什么的，解决什么问题
2. **涉及知识点**：列出会用到的前面教程中的技能
3. **硬件清单**：需要哪些模块和元器件
4. **电路连接**：详细的接线表或接线图
5. **代码思路**：分步骤解释程序逻辑
6. **关键代码解析**：重点函数和逻辑片段讲解
7. **运行效果**：上传后应该看到什么
8. **常见问题**：可能遇到的问题和排查方法
9. **扩展挑战**：可以进一步改进的方向

## .ino 代码结构

1. 顶部大注释：项目介绍、学习目标、硬件连接
2. 库引用和宏定义
3. 全局变量
4. setup()：初始化
5. loop()：主循环
6. 自定义函数
7. 详细中文注释：解释每一步"为什么"

## 写作风格

- 所有注释和文档使用中文
- 每行关键代码都要有注释
- 遇到新概念要解释
- 解释"为什么这样写"，不只是"做什么"
- 每个项目都要是完整可运行的
