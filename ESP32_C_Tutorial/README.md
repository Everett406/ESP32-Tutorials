# ESP32 学 C 语言教程

这套教程教你用 ESP32 学习 C 语言。我们继续使用 Arduino IDE（因为你已经配置好了），但会尽量写纯 C 语法，让你理解 C 语言的本质，而不是只停留在 Arduino 的封装之上。

## 为什么要用 ESP32 学 C？

- **立即可见效果**：代码一上传，LED 亮、串口输出、传感器读数，学习反馈很快。
- **真实硬件环境**：C 语言在单片机上的概念（GPIO、寄存器、中断、内存）和电脑上略有不同，直接在 ESP32 上学更贴近实际应用。
- **平滑过渡**：学完这套 C 基础后，你可以继续深入 Arduino 库源码、ESP-IDF、FreeRTOS，甚至自己写驱动。

## 学习路线

建议按编号顺序学习，每课都建立在前面课程的基础上。每节课都包含：

1. **概念讲解**：用中文详细解释专业术语
2. **写法变体**：同一个功能有哪些等价的正确写法
3. **常见陷阱**：哪些代码"看起来对，实际错"
4. **课后练习**：巩固所学

C16 是这些内容的汇总复习版，可以在学完 C01~C15 后快速回顾。

## 和 Arduino 教程的关系

- `ESP32_Tutorial_Series/`（Arduino 教程）：侧重"用 Arduino 方式快速做出东西"。
- `ESP32_C_Tutorial/`（本教程）：侧重"理解 C 语言本身和底层原理"。

两套教程可以并行学习。例如：
- 上午学 C02 变量类型，下午在 Arduino 教程 04 中看变量怎么用到 ADC 里。
- 学完 C08 指针后，再回去看 Arduino 教程 08 的蓝牙串口，会更容易理解数据缓冲。

## 怎么用

1. 打开 Arduino IDE。
2. 选择 **文件 → 打开**，找到 `D:\Arduino\ESP32_C_Tutorial\Cxx_xxx\Cxx_xxx.ino`。
3. 选择开发板 **ESP32 Dev Module**，选择 COM 口，上传。
4. 打开串口监视器，波特率 **115200**。
5. 阅读代码中的中文注释，跟着做课后的练习。

## 学习建议

1. **不要跳课**：C 语言是层层递进的，指针没学好，结构体和函数指针会很痛苦。
2. **动手做练习**：每个文件末尾都有练习，一定要自己写一遍，不要只看。
3. **不懂就问**：如果某个概念（比如指针、位运算）看了注释还是迷糊，这是正常的。把具体问题告诉我，我可以再帮你拆细。
4. **错误也是学习**：程序编译不过、输出不对，都是学习机会。把报错贴出来，我们一起看。

## 学完这套能做什么

- 看懂并修改 Arduino/ESP32 的开源库源码
- 理解 ESP-IDF 的 C 代码结构
- 自己写驱动程序、通信协议
- 为嵌入式开发岗位面试打下基础

## 下一步

学完 C 基础后，可以挑战：

- 用纯 C 重写之前 Arduino 教程里的项目（去掉 `String` 类，用 `char[]`）
